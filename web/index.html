Where does the model come from?

The part before /chat/completions, usually ending in /v1.

Pick a suggestion or type any model the provider serves.

API key

Kept in the gateway's secrets file (secrets.json in Deskfish's data folder, readable only by the account that runs it), one key per provider. Save it empty to clear it.

Settings

Kept by Deskfish itself, so VS Code and this page show the same values. The model and the API key have their own buttons in the chat.

Scheduled tasks

They run while Deskfish runs, with or without VS Code or this page. A time missed while it was not running is skipped, not run late.
